Algorithm notes

LDA methodology

How a linear decision rule separates phishing and legitimate websites, and what assumptions that rule makes.

Fisher’s discriminant criterion

LDA seeks a projection where class means are far apart compared with the variation within each class. For phishing and legitimate websites, the objective is:

J(w) = (wᵀ SB w) / (wᵀ SW w)

Within-class scatter accumulates variation of each observation around its class mean:

SW = Σk Σi:yᵢ=k (xᵢ − μk)(xᵢ − μk)ᵀ

Between-class scatter measures how far each class mean is from the overall mean:

SB = Σk nk(μk − μ)(μk − μ)ᵀ

The stationary directions satisfy SBw = λSWw. In a two-class task, between-class scatter has rank at most one, so at most one discriminant direction exists.

Classification rule

With class-conditional Gaussian features and a shared covariance matrix, each class receives a linear discriminant score. Assign the sample to the class with the larger score. The shared covariance assumption produces a linear decision boundary.

Classification LDA directly predicts classes and probabilities. Dimensionality-reduction LDA instead uses the discriminant projection to transform features for a later task; the concepts share the same separation motivation but are used differently.

Assumptions and limits

  • Shared covarianceBoth classes are modeled with one pooled covariance matrix.
  • Gaussian class featuresClass distributions are approximated by multivariate Gaussians.
  • Correlated inputs are allowedIndependence is not required, though strong collinearity can make estimates unstable.
  • Linear separationCurved or highly interactive boundaries may not be represented well.

Experiment configuration
